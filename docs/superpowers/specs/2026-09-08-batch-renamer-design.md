# 文件批量改名工具：第一版设计

## 目标与范围

面向 Windows 11 的中文桌面工具，使用 Python 3.11 或更高版本和 PySide6。用户已确认多选文件、查找替换、前后缀、编号、预览、冲突检查和撤销的功能范围，并于 2026-09-08 授权开始实施。

不包含子文件夹递归、正则、AI 改名、账号、联网服务或安装包制作。第一版从本地运行，后续再按需要打包 exe。

## 界面与流程

一个可调整大小的中文窗口。顶部提供添加文件、移除选中、清空；规则区域包含查找、替换、前缀、后缀，以及可选编号的起始值和位数；中间表格显示原名、新名、所在目录和状态；底部显示待改名与冲突数量，提供执行和撤销。

添加文件保留选择器返回的顺序，后续添加追加到末尾；相同路径忽略重复添加。编号严格按表格顺序产生，不允许通过点击列标题隐式改变顺序。修改规则立即更新预览。执行前确认框展示改名数量，取消不触碰文件。

## 规则

- 仅处理文件名主体，保留最后一个扩展名及其大小写；例如 archive.tar.gz 的主体是 archive.tar。无扩展名文件整体视为主体。
- 查找替换按大小写敏感的普通文字匹配；查找为空时跳过替换，替换为空允许删除匹配文字。
- 应用顺序为查找替换、前缀、后缀、编号。编号启用后以“_001”形式追加到主体末尾、扩展名之前。
- 起始编号为非负整数；位数可设为 1–8，仅为最少位数，不截断较大的编号。
- 没有变化的行显示“无需修改”，不执行文件操作。

## 安全与失败处理

- 只在原目录内改名，不移动目录、不覆盖、不删除文件内容；拒绝目录和符号链接。
- 检查空名称、Windows 禁用字符、控制字符、结尾空格或点、保留设备名，以及同目录内不区分大小写的重复目标名。
- 目标已存在则阻止执行，包括其他已选文件占据的目标。第一版不支持交换文件名、链式占用和仅改变大小写的改名，并在预览中明确提示。
- 有任意冲突时整批禁止执行；执行前重新检查源文件身份、目标占用与预览一致性。源文件已被替换、修改或移走时要求刷新预览。
- Windows 实际改名使用不覆盖目标的操作，防止预检后其他程序创建目标导致覆盖。
- 审查补强：使用 Windows 文件句柄锁定源文件、核对句柄身份后原地改名；锁定期间禁止外部写入或替换，避免检查与改名之间被替换。
- 执行期间禁用列表、规则和操作按钮。中途失败停止后续操作，按逆序尝试恢复本批已经成功的项目；恢复前核对文件身份及原路径空闲。
- 若恢复失败，逐项显示真实路径和失败原因，保留仍需恢复的项目供用户重试。不能把部分成功报为整批成功。

## 撤销

当前应用会话内保留最近一次成功执行的路径映射与文件身份快照。只有下一次实际执行成功后才替换历史；单纯预览、取消、零改名不清除历史。

撤销前检查原名未被占用、改名后的文件仍与记录一致；冲突时不执行。撤销期间出现失败，尝试恢复到撤销前状态，并如实显示未恢复项目。重启应用后不提供撤销，界面和使用说明明确这一点。

## 代码职责

- `renamer/core.py`：名称转换、预览与冲突检查，不依赖界面。
- `renamer/operations.py`：实际执行、失败恢复及会话内撤销记录。
- `renamer/windows.py`：Windows 原生句柄与不覆盖改名。
- `renamer/app.py`：PySide6 界面、确认提示与状态展示。
- `renamer/__main__.py`：启动入口。
- `tests/test_core.py`、`tests/test_operations.py`：规则与文件操作的自动化测试。
- `requirements.txt`、`README.md`、`.gitignore`：依赖、启动说明和本地环境排除规则。

## 实施顺序与验收

1. 准备项目内虚拟环境与 PySide6；不修改系统 PATH 或 Git 配置。先检查可用运行时，需要安装到系统或写入授权目录之外时按实际权限流程处理。
2. 先编写名称规则和冲突检查测试，再实现预览逻辑。覆盖中文、扩展名、编号、空主体、保留名与重名。
3. 在临时目录中测试并实现执行与撤销。覆盖目标抢占、源文件变化、执行中途失败及恢复失败，验证原有文件内容始终不被覆盖。
4. 连接中文界面与上述逻辑，提供数量提示、确认框和逐项错误。
5. 运行自动化测试和 Qt 启动冒烟检查，用临时示例文件验证“添加→预览→执行→撤销”。区分自动化验证与实际可见窗口的人工验证，不将后台启动等同于完整交互验收。
6. 编写可复制的本地启动说明，交付可运行版本与已知限制。没有用户明确授权时不提交 Git。
