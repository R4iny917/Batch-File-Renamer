# Batch File Renamer

一个面向 Windows 的中文文件批量改名工具。设置规则后，先对照原文件名和新文件名，再确认执行；本次打开期间可撤销最近一次成功改名。

## 下载与启动

在仓库的 [Releases 页面](https://github.com/R4iny917/Batch-File-Renamer/releases) 查找已发布的 Windows 便携包。若尚无可用附件，可按下方说明从源码构建。

1. 下载 `Batch File Renamer-Windows-x64.zip`，完整解压。
2. 打开解压后的 `Batch File Renamer` 文件夹。
3. 双击 `Batch File Renamer.exe`。

便携版无需安装 Python 或配置开发环境。请保留 EXE 旁边的 `_internal` 文件夹，分享时发送整个 ZIP。当前包面向 Windows 10/11 x64，已在 Windows 11 验证；尚未进行代码签名，首次运行下载的程序时可能出现发布者未知提示。

## 功能

- 按普通文字查找替换，添加前缀、后缀及递增编号。
- 实时预览新名字，提示非法名称、重名和目标占用。
- 选取原文件名中的部分文字，直接填入查找栏。
- 复制文件名，支持列表多选后逐行复制。
- 撤销最近一次成功批次；失败时尝试回滚，并提供未完成操作的恢复入口。
- 根据屏幕和系统缩放适配窗口，规则侧栏支持滚动。

当前不支持文件夹递归、正则表达式或 AI 改名。

## 使用方法

1. 点击“添加文件”，选择一个或多个文件；重复添加会去重。
2. 在左侧设置查找替换、前后缀或编号，查看右侧的新文件名与状态。
3. 有错误时先修改规则或移除对应行；长文件名和错误信息可悬停查看。
4. 点击“执行改名”，核对确认信息后执行。成功后规则会重置，避免重复追加。
5. 需要恢复原名时，在关闭程序前点击“撤销上次改名”。

“移除选中”和“清空”只改变列表，不删除磁盘文件，也不清除已有撤销记录。

### 将部分文件名填入查找

选中文件，在底部“文件名”框中拖选需要替换的文字，再点击“填入查找”。文本框不包含最后一个扩展名，支持 Ctrl+C 和右键复制。没有选中文字时会提示选取，保留原有查找内容。

在文件列表中按 Ctrl+C，会复制选中的完整原文件名（包含扩展名）；多选时每行一个。

## 命名规则

规则按 **查找替换 → 前缀 → 后缀 → 编号** 的顺序应用，最后一个扩展名及其大小写保持不变。

| 原文件名 | 设置 | 新文件名 |
| --- | --- | --- |
| `照片.JPG` | 前缀 `旅行_`、后缀 `_精选`、从 1 开始的 3 位编号 | `旅行_照片_精选_001.JPG` |
| `IMG_001.jpg` | 查找 `IMG_`，替换为 `假期_` | `假期_001.jpg` |
| `archive.tar.gz` | 查找 `tar`，替换为 `zip` | `archive.zip.gz` |

- 查找区分大小写。查找留空时跳过替换，替换留空时删除匹配文字。
- 编号从设定的起点开始，允许从 0 开始，位数可选 1–8；位数是最少位数，较大的数字不会被截断。
- 编号按文件列表顺序分配。初始顺序来自文件选择器，后添加的文件排在末尾。
- 支持没有扩展名的普通文件；所有操作均在原目录完成。

## 文件安全与撤销限制

程序不覆盖已有文件。非法 Windows 名称、同批次目标重名、仅改变大小写，以及目标仍被其他已选文件占用时，会阻止执行。

执行前会重新核对文件身份、大小、修改时间和目标占用，并通过 Windows 文件句柄绑定操作，短暂阻止其他程序写入或替换文件。外部修改后请刷新预览；遇到文件占用时，关闭占用程序后重试。

- 仅处理普通文件，不处理目录、符号链接及带重解析点属性的文件，例如部分云端占位文件。
- 中途失败会尝试逆序恢复；若恢复未完成，可查看详情并“重试恢复”，恢复前不能开始新批次。
- 撤销只保留最近一次成功批次，包含已从列表移除的文件。外部改名、内容变化、文件替换或原名被占用可能阻止撤销。
- **关闭程序后撤销记录消失。** 批量改名不是原子事务，强制结束进程或断电后无法自动恢复；操作期间请勿让其他程序修改同一批文件。
- 长路径支持取决于 Windows 与所在文件系统；失败会在预览或执行结果中报告。

## 从源码运行

需要 Windows、Python 3.11 或更高版本。在仓库根目录打开 PowerShell：

```powershell
# 创建项目虚拟环境
py -3 -m venv .venv
# 安装运行依赖
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
# 启动应用
& .\.venv\Scripts\python.exe -m renamer
```

完成环境安装后，也可双击 `start.cmd`。它使用项目虚拟环境启动源码，保留命令行窗口便于查看异常。移动项目或更换电脑后应重新创建 `.venv`，不要将其作为便携应用分发。

## 测试

在仓库根目录执行：

```powershell
# 常规测试，包括 Qt 后台界面测试
& .\.venv\Scripts\python.exe -m unittest discover -s tests -v
# Windows 原生交互测试，需要可用桌面，单独运行
& .\.venv\Scripts\python.exe tests/test_native_ui.py --run
# 检查 Python 文件能否编译
& .\.venv\Scripts\python.exe -m compileall -q renamer tests
```

测试使用临时文件，覆盖命名规则、冲突、文件内容保持、回滚、恢复、状态管理和界面交互。常规测试发现原生测试时会跳过；原生测试另行检查真实焦点、选区、字重、小窗口滚动和确认弹窗。两类测试都不能替代 UI 视觉验收。

## 构建便携版

在 Windows x64 的项目环境中执行：

```powershell
& .\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
& .\.venv\Scripts\python.exe build.py
```

构建输出：

```text
dist/
├── latest/Batch File Renamer/       最新应用，包含 EXE 和运行依赖
├── previous/                       前一版本（已有版本时保留）
└── Batch File Renamer-Windows-x64.zip
```

构建前请完成需要的撤销或恢复，并关闭这两个目录中的程序。构建脚本先在四档缩放下运行原生界面检查（需要可用的 Windows 桌面），全部通过后生成新包，成功后轮换版本并清理更早产物，仅保留最新 ZIP；构建输出不提交到 Git。

`Batch File Renamer.spec` 定义打包入口、资源和无控制台模式；`build.py` 负责生成图标、调用 PyInstaller、压缩和版本轮换。
