# 文件批量改名工具

Windows 11 中文桌面工具：先预览新名字，再确认批量改名，支持本次打开期间撤销最近一次操作。

## 现在怎么打开

双击项目根目录的 **start.cmd**。当前电脑的项目环境已准备好，无需额外安装。

也可以在项目目录打开 PowerShell，执行：

```powershell
& .\.venv\Scripts\python.exe -m renamer
```

启动器的命令行窗口会随工具一起保留，便于看到异常；使用完工具后可以关闭它。

## 使用步骤

1. 点击“添加文件”，可以多选；同一个文件只添加一次。
2. 设置查找替换、前缀、后缀或编号，查看“原文件名 / 新文件名”对照。
3. 如果出现错误，先修改规则或移除对应行。长文件名及错误可悬停查看完整内容。
4. 点击“执行改名”，确认数量后开始。成功后会重置规则，避免误将同一前缀重复追加。
5. 想恢复原名时，点击“撤销上次改名”。撤销范围包括已从列表移除的文件。

所有改名都在原目录进行。“移除选中”和“清空列表”只影响列表，不删除文件。

## 规则示例

| 原文件名 | 规则 | 新文件名 |
| --- | --- | --- |
| 照片.JPG | 前缀 `旅行_`，后缀 `_精选`，编号从 1 开始、3 位 | 旅行_照片_精选_001.JPG |
| IMG_001.jpg | 查找 `IMG_`，替换为 `假期_` | 假期_001.jpg |
| archive.tar.gz | 查找 `tar`，替换为 `zip` | archive.zip.gz |

- 查找区分大小写，按普通文字匹配；查找留空表示跳过替换，替换留空表示删除匹配文字。
- 处理顺序：查找替换 → 前缀 → 后缀 → 编号。最后一个扩展名及其大小写保持不变。
- 编号按表格显示顺序分配；选择器返回顺序就是初始顺序，后加文件排在末尾。位数是最少位数，不截断较大数字。
- 支持无扩展名文件。不支持文件夹递归、正则、AI 改名。

## 文件安全与撤销边界

- 不覆盖已有目标。非法 Windows 名称、同批次目标重名、仅改变大小写、目标仍被其他已选文件占用时，禁止执行。
- 仅处理普通文件，不处理符号链接、目录或带重解析点属性的文件（例如部分云端占位文件）。
- 执行前重新核对文件身份、大小、修改时间和目标占用。外部程序更改文件后，请先刷新预览。
- 实际改名绑定已核对的 Windows 文件句柄，短暂阻止其他程序写入或替换该文件；正在被其他程序写入的文件可能提示占用，请关闭对应程序后重试。
- 操作中途失败会尝试逆序恢复；若恢复仍失败，界面保留详细路径及“重试恢复”入口，未恢复前禁止开始新批次。
- 撤销只保留最近一次成功批次；关闭工具后记录消失。外部改名、文件被替换或修改、原名被占用会阻止撤销。
- 批量文件系统操作不是一个原子事务。操作期间请勿让其他程序修改同一批文件；进程被强制结束或系统断电后无法自动恢复。
- 长路径是否可操作取决于 Windows 和所在文件系统，失败会在预览或执行结果中报告。

## 在其他电脑准备环境

需要 Windows 和 Python 3.11 或更高版本。在项目目录执行：

```powershell
py -3 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
& .\.venv\Scripts\python.exe -m renamer
```

如默认下载源很慢，可以仅对本次安装使用清华镜像：

```powershell
& .\.venv\Scripts\python.exe -m pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

当前 `.venv` 基于 Codex 自带 Python 3.12 创建，依赖该基础运行时所在路径。移动项目、换电脑或运行时被清理后，应重新创建虚拟环境；不要复制 `.venv` 作为安装包。所有项目依赖只安装在 `.venv`，没有修改系统 PATH。

## 验证

```powershell
& .\.venv\Scripts\python.exe -m unittest discover -s tests -v
& .\.venv\Scripts\python.exe -m compileall -q renamer tests
```

测试只使用临时目录，包括规则、冲突、文件内容保持、失败回滚、恢复和 Qt 界面操作。界面测试使用 offscreen 后台模式，不等同于真实桌面的人工验收。

## 代码位置

- `renamer/core.py`：名称规则、快照及预览。
- `renamer/operations.py`：改名、撤销与失败恢复。
- `renamer/windows.py`：通过 Windows 文件句柄锁定并改名，禁止覆盖。
- `renamer/app.py`：中文界面及后台操作线程。
- `tests/`：自动化测试。
- `docs/superpowers/`：设计与实施记录。
